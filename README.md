# Office Roulette

Würfelt per Klick eine zufällige Folge von **The Office (US)** aus – über alle 9 Staffeln hinweg – und verlinkt zur Serie bei Netflix und Prime Video (Deutschland).

- Glücksrad-Animation im Stil eines alten Röhrenmonitors
- Staffeln an- und abwählbar
- Zufälliges Zitat aus der Serie bei jedem Öffnen

Die ganze App steckt in `index.html`, ohne Build-Schritt. Online über GitHub Pages.
